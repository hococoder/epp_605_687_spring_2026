Example - Querying Historical Data

Let's look at how you can read historical data, such as weight, instead of static information such as the birthdate from before. In the HealthKitDataHelper class, let's add a method that will collect data from the last 7 days, and call it readHistoricalData. It will take in a HKSampleType as well as a unit. The query to the HealthKit store can take some time, and possibly throw errors, so mark it with async throws. For this example, we'll just return the most recent value as a Double

@Published var weight: Double = 0.0

//Query to read data from the past 7 days
func readHistoricalData(for typeIdentifier: HKQuantityTypeIdentifier,
                          unit: HKUnit) async throws -> Double

Restrict the time range for our query by using HKQuery.predicateForSamples, providing start and end dates, as well as the strictEndTime which dictates that the sample's end time must be less than the query's end time

   //restrict the date range
  let mostRecentPredicate = 
    HKQuery.predicateForSamples(withStart: Date() - 7*86400,
                                end: Date(),
                                options: .strictEndDate)

We can also sort the data with a HKSampleQueryDescriptor. Similar to Swift Data, we can provide a predicate and a sort descriptor for the query we want to make. Pass in the typeIdentifier and the mostRecentPredicate we made before.

   //sort the returned values
    let queryDescriptor = HKSampleQueryDescriptor(
    predicates:[.quantitySample(type: HKQuantityType.quantityType(forIdentifier: typeIdentifier)!, predicate: mostRecentPredicate)],
      sortDescriptors: [SortDescriptor(\.endDate, order: .reverse)]
  )

The query descriptor will actually sort things in reverse, so we'll get the most recent value.

Now let's make the query. Recent updates to HealthKit have made it a lot easier to process queries!

     let results = try await sortDescriptor.result(for: HKHealthStore())
    guard let mostRecentSample = results.first else { return 0 }
    return mostRecentSample.quantity.doubleValue(for: unit)

The query descriptor gets the results via the async call result(for: HKHealthStore), and we use a guard to look for the mosts recent sample, which is the first value in our collection. If that is successful, we can convert that value to the proper unit via HealthKit's doubleValue(for: HKUnit) call.

With this in place, go up and and make a readWeight() function to use here, and add it to the loadData function.

func readWeight() async throws {
  self.weight = try await readHistoricalData(for: .bodyMass, unit: HKUnit.pound())
}

We’re going to get the patient’s body mass, so that is the type we’ll pass in, and if a value gets sent back and nothing is thrown, set the weight property to the returned value!

Before running this in the simulator, add a field to the Form in our view to display the weight

HStack {
  Text("Weight (lbs)")
  Spacer()
  Text("\(numberFormatter.string(from: NSNumber(value: hkData.weight))!)")
}

Run this in the simulator, and you can see that the most recent weight is being shown in our view as intended. Historical data such as weight can easily be retrieved from the health kit store by defining the proper parameters for the sample query, and once you have that data, you can display it on screen just like you want.
