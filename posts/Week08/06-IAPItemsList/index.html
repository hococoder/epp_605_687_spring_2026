Example - Getting a List of IAP Items

The page shown in the video above is here

Let's look at how to get a list of In App Purchase items from the App Store. To start, I've made a demo view that has a button on it that allows the user to view the In App Purchases. The display of the new view in a sheet should be very familiar by now, so I won't go through it. There are some methods that get called on the button push, and also the task when loading, which we'll talk about shortly.

import SwiftUI
import StoreKit

struct IAPView: View {
  
  @Environment(IAPManager.self)
  private var iapManager: IAPManager

  var body: some View {

    VStack(spacing: 20) {
      Text("Products")
        .font(.largeTitle)
      Spacer()
      ForEach(iapManager.products) { product in
        Button {
          Task {
            do {
              try await iapManager.purchase(product)
            } catch {
              print(error)
            }
          }
        } label: {
          Text("\(product.displayPrice) - \(product.displayName)")
        }
      }
      Spacer()
    }.task {
      do {
        try await iapManager.loadProducts()
      } catch {
        print(error)
      }
    }
  }
}

There is an IAPManager in there to help us, which we'll define next. Start by defining the class (don't forget to import StoreKit), In the body of the class, define an array called products that has the list of products from the store, a boolean to denote whether the list has been loaded or not, and a Set containing the purchased product ids:

@MainActor
@Observable
class IAPManager {

  let productIds = ["edu.jhu.ep.steele.josh.EPExampleApp.S2026.DisableAdsIAP"]

  private(set) var products: [Product] = []
  private var productsLoaded = false
  private(set) var purchasedProductIDs = Set<String>()

Note that for the simplicity of this example, I've set a static list of productIds. You may want to treat this differently in your app depending on how dynamic your IAP list is!

Next, define a method to load the products from the productIds array:

   func loadProducts() async throws {
    guard !self.productsLoaded else { return }
    self.products = try await Product.products(for: productIds)
    self.productsLoaded = true
  }

This loads the products if they haven't already, via the Product.products call, and sets productsLoaded to true.

Next, make a purchase function that will attempt to purchase a product and check its status:

   func purchase(_ product: Product) async throws {
    let result = try await product.purchase()

    switch result {
    case let .success(.verified(transaction)):
      // Successful!
      await transaction.finish()
      await self.updatePurchasedProducts()
      products.removeAll(where: { prod in prod == product })
    case .success(.unverified(_, _)):
      // Successful purchase but transaction/receipt can't be verified
      break
    case .pending:
      // Transaction waiting on SCA (Strong Customer Authentication) or
      // approval from Ask to Buy
      break
    case .userCancelled:
      break
    @unknown default:
      break
    }
  }

product.purchase() is called via async/await, and if successful, a result comes back. You can check the properties of that request to see if the purchase was successful, successful but unverified, pending, or cancelled by the user.

Once the purchase is successful, and it is verified, you can finish the call via transaction.finish() and call updatePurchasedProducts, which carries out the needed action for our purchased product:

   func updatePurchasedProducts() async {
    for await result in Transaction.currentEntitlements {
      guard case .verified(let transaction) = result else {
        continue
      }

      if transaction.revocationDate == nil {
        self.purchasedProductIDs.insert(transaction.productID)
        if transaction.productID == "edu.jhu.ep.steele.josh.EPExampleApp.S2026.DisableAdsIAP" {
          unlockAds()
        }
      } else {
        self.purchasedProductIDs.remove(transaction.productID)
      }
    }
  }

The successful purchase calls unlockAds:

   func unlockAds()
  {
    let defaults = UserDefaults.standard
    defaults.set(false, forKey: "showAds")
  }

If you have an ad view that is visible based on the status of the "showAds" key in user defaults, setting that key to false would hide the ad.

In App Purchases can get a whole lot more complex, but this should give you the idea of the basics needed to get things started.
